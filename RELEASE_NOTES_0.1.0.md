## Kyty UX Launcher 0.1.0 (alpha)

First public alpha. A modern launcher for the KytyPS5 emulator, with a game library, a full settings editor and built-in emulator updates.

### Highlights

- Animated, spring-based interface across every screen.
- **Game library** with cover art, metadata, play time, search and sorting.
- **One-click launch** with no console window; clean shutdown when you press Stop.
- **Settings editor** covering every emulator option, with a review screen that lists only what changed before anything is written.
- **First-run setup**: detects an existing KytyPS5 install, lets you pick its folder, or downloads and installs it quietly. Then sets up profile, GPU, system options and game folders.
- **Emulator updater**: checks GitHub Releases and installs new builds in the background, keeping saves and settings. Failed installs roll back automatically.

### Install

Download `Kyty.Launcher_0.1.0_x64-setup.exe` below and run it. It installs per user (no admin needed). Windows SmartScreen may show a warning because the installer is not code-signed: choose **More info -> Run anyway**.

### Known limitations

- Alpha quality; please report issues.
- Per-game custom settings are respected when launching but can only be edited with the emulator's own launcher for now.
- Zipped/archived games and the controller input-mapping editor are not supported yet.
- The launcher does not update itself yet; update it by installing a newer release.
- Microphone names come from Windows audio and should match the emulator's, but this has had limited testing.
